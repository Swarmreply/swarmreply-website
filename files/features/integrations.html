Frequently asked questions

Which tools does SwarmReply integrate with?

SwarmReply connects with the tools local businesses already run — including Jobber, Square, HubSpot, Shopify, Mindbody, Calendly, Acuity, Stripe, and Zapier — so review requests and workflows trigger automatically from the systems you use.

What does an integration actually do for me?

It removes the manual step. When a job is marked complete in Jobber or a sale closes in Square, SwarmReply can automatically send that customer a review request at the perfect moment — no list to remember, no button to click.

Do I need a developer to set these up?

No. Most connect with a few clicks. For anything custom, our Zapier connection lets you wire SwarmReply to thousands of apps without code.

Is there an API?

Yes. SwarmReply provides an API key so you can build your own integrations and trigger review requests or pull data programmatically.

Are integrations an extra cost?

No. Integrations are part of the flat $99/month plan. We don't gate connectivity behind a higher tier the way enterprise platforms do.
